# Project Knowledge

Committed template of the external `ADS-project-knowledge/` workspace.

## How To Use This Workspace

- Keep project-owned memory, reports, and workflow notes here instead of writing them back into `AI-Dev-Shop-speckit/`.
- This workspace is the writable sibling to `AI-Dev-Shop-speckit/` inside the host project.
- `.local-artifacts/` is for ignored local scratch output only; retained artifacts belong under `reports/`.

## Folders

- `governance/`: project governance, including the live constitution
- `memory/`: live project memory files only (`project_memory.md`, `learnings.md`, `project_notes.md`, `memory-store.md`)
- `reports/`: retained writable artifacts, benchmarks, audits, continuity logs, and pipeline outputs
- `.local-artifacts/`: ignored local-only scratch output
- `meta/`: workspace metadata and workflow notes
- `tmp/`: short-lived transport copies and other temporary files
